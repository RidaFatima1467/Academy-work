# AFL Player Data Analysis
## Analysis Performed

The project answers these questions:

* Which teams have played the most games?
* What is the distribution of player ages?
* Which teams have the highest number of players?
* How does player weight vary across teams?
* Which teams have the highest average fantasy points?
* Who are the Top 15 goal scorers?
* How many records are available for each season?

## Dataset

The analysis uses the merged AFL player dataset from Week 1.

The `player_teams` column is used to analyze teams because the dataset does not contain a position column.

## Visualizations

The project includes charts for each major analysis.

Each chart has:

* Business Question
* 2–3 Observations
* Business Insight
