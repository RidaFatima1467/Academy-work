**SQL Foundations for Data Science**

This project is part of the SQL Foundations for Data Science task.
The purpose of this project is to learn how SQL and PostgreSQL are used to store, retrieve, filter, sort, and summarize data.

**Dataset**

The project uses the **Superstore Sales Dataset** from Kaggle.

**Dataset source:**

https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

The dataset contains sales information such as:

* Order details
* Customer information
* Product information
* Sales
* Quantity
* Discount
* Profit
* Region and location

**Tools Used**

* PostgreSQL
* pgAdmin 4
* SQL
* Superstore Sales Dataset

**Table**

The CSV dataset was imported into a PostgreSQL table named:

`superstore_sales`

The table contains 21 columns, including:

* Row ID
* Order ID
* Order Date
* Ship Date
* Ship Mode
* Customer ID
* Customer Name
* Segment
* Country
* City
* State
* Postal Code
* Region
* Product ID
* Category
* Sub-Category
* Product Name
* Sales
* Quantity
* Discount
* Profit

**Setup Steps**

1. Install PostgreSQL and pgAdmin 4.
2. Open pgAdmin.
3. Create a database in postgres.
4. Open the Query Tool.
5. Create the `superstore_sales` table.
6. Download the Superstore CSV dataset from Kaggle.
7. Import the CSV file into the `superstore_sales` table.
8. Verify that the data was imported correctly.
9. Run SQL queries to explore and analyze the data.
