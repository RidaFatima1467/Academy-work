In this task, I learned about data visualization using Python.
I used an Amazon sales dataset to create different types of charts and understand the data better.
Visualizations
Bar Chart: Used for categorical data.
Histogram: Used for numerical data and shows the distribution of values.
Line Plot: Used to show data trends.
Boxplot: Used to understand data spread and find outliers.
Subplot: Used to show multiple charts in one figure.
Heatmap: Used to show relationships between numerical values using colors.
